# v1.4.0 背景設計・現行距離仕様の調査

更新日：2026-09-16  
状態：**背景カテゴリ・探索背景の切替距離・初期画像9枚は決定済み。画像の絵柄と実ファイルは未制作。**  
関連：[`v1.4.0-仕様.md`](./v1.4.0-仕様.md) の「9. シーン背景画像」。本書は背景制作の一覧と既存コードの調査記録を兼ねる。

## 1. 決定したカテゴリ

| カテゴリ | 対象シーン | 距離による切替 |
| --- | --- | --- |
| タイトル | タイトル | なし |
| 拠点昼 | ホーム、制作、持ち物 | なし |
| 拠点夜 | 睡眠 | なし |
| 探索 | 探索、入手、戦闘、勝利、逃走 | **あり。探索カテゴリだけ。** |
| リザルト | ゲームオーバー | なし |
| 履歴 | プレイ履歴、解放ストーリー一覧、実績、図鑑など、v1.4でタイトルから新たに追加する閲覧シーン | なし |
| その他 | ストーリー本文 | なし。ストーリーIDごとの個別背景指定に対応するが、初期データではすべて共通背景を使用する。 |
| 対象外 | リフレッシュ | 背景画像の設定対象としない。 |

現行の登録は [`programs/main.js`](../programs/main.js) の13シーン。`loading_scene.js` は存在するが登録されておらず、現時点の画像対象外。新規閲覧シーンの正確な名称と数は実装時に決める。ストーリー一覧は「履歴」、そこから再生した本文は「その他」の背景を用いる。

### 背景選択ルール（確定）

1. ストーリー本文に個別背景が明示されていれば最優先する。ただし**v1.4初期のストーリーデータでは個別背景を設定せず**、「その他」の固定背景を使う。
2. 「探索」の5シーンでは、現在の到達距離以下にある最大の開始距離の画像を選択する。距離は保存・計算上の単位mで統一する。
3. 探索以外のカテゴリは距離を参照せず、カテゴリごとの固定背景を使う。タイトル・履歴などで最高記録やプレイ中の距離を背景選択に流用しない。
4. 画像未設定・読込失敗の場合はカテゴリのデフォルト画像を試し、それもなければ従来の背景色にフォールバックする。探索の0km画像を探索カテゴリのデフォルトにも指定可能とする。
5. 背景は画面の最背面で描画し、UIやボタンの表示・操作を妨げない。戦闘だけ敵別画像に変える等の例外は追加しない。

### 探索の切替距離（確定）

| 現在の到達距離 | 使用する背景 | 開始距離（データ定義値） |
| --- | --- | ---: |
| 0km以上、50km未満 | 探索 0km | `0` m |
| 50km以上、100km未満 | 探索 50km | `50000` m |
| 100km以上 | 探索 100km | `100000` m |

100km以降は上限なし。探索・入手・戦闘・勝利・逃走はすべて同じ距離帯の画像を共有する。50kmや100kmにちょうど到達した場合は新しい画像を選ぶ。敵の出現解禁ルールや気力消費量は背景変更では改変しない。

## 2. 制作する背景画像：計9枚

ファイル名と保存場所は実装を揃えやすくするための**推奨納品規約**。絵柄・構図の具体的内容は画像制作時に決定できる。ストーリー専用画像はこの初期リストに含めない。

| No. | 背景用途 | 推奨ファイルパス | 枚数 |
| ---: | --- | --- | ---: |
| 1 | タイトル | `images/backgrounds/title.webp` | 1 |
| 2 | 拠点昼（ホーム・制作・持ち物） | `images/backgrounds/base_day.webp` | 1 |
| 3 | 拠点夜（睡眠） | `images/backgrounds/base_night.webp` | 1 |
| 4 | 探索 0km以上～50km未満 | `images/backgrounds/exploration_000.webp` | 1 |
| 5 | 探索 50km以上～100km未満 | `images/backgrounds/exploration_050.webp` | 1 |
| 6 | 探索 100km以上 | `images/backgrounds/exploration_100.webp` | 1 |
| 7 | リザルト（ゲームオーバー） | `images/backgrounds/result.webp` | 1 |
| 8 | 履歴・各種一覧（図鑑・実績等） | `images/backgrounds/history.webp` | 1 |
| 9 | その他（ストーリー共通） | `images/backgrounds/story_default.webp` | 1 |

- **制作サイズ：1080 × 1920 px、縦長9:16、全9枚共通を推奨。** 現行コードの `SCREEN_W=1080`、`SCREEN_H=1920` と一致する。`index.html` でもキャンバスを同じ比率で画面内に縮小表示している。画像はキャンバス全面用に作り、テキスト・ボタン等のUIを描き込まない。
- 形式は容量と読み込みの面から `.webp` を推奨し、上記パスはそれに合わせたもの。PNGで制作する場合は実装前に拡張子を統一する。透過は必須ではない。編集用の高解像度原画を別保管するのは任意だが、ゲームに配置する9枚は1080×1920pxを基準にする。
- 文字が重なる部分は視認性を確保できるよう、実装側で半透明パネル等を用意する。背景画像にボタンや説明テキストを焼き込まない。
- 画像の具体的な風景・彩色、ロード時のスケーリング／トリミング方式は未決定。画像自体は9:16を基準にして、余計なトリミングを必要としない構図を想定する。
- `images/backgrounds/` は**追加予定のディレクトリ**。現時点で画像を配置済みという意味ではない。

## 3. v1.3.3 の距離関連仕様（コード確認）

### 3.1 探索距離と気力

[`programs/scenes/search_scene.js`](../programs/scenes/search_scene.js)：探索が1回進行するごとに移動距離が**100m増加**。気力消費は更新前の距離 `d`（m）で `5 + floor(d / 10000)`。0～9.9kmで5、10～19.9kmで6、20～29.9kmで7、…と10kmごとに1増加する。9.9kmから10kmに到達する探索は旧距離で算出するため5消費し、次の探索から6消費する。変化後に気力が負ならゲームオーバー判定。

ホーム・制作・入手・睡眠の警告は `気力 < (5 + floor(距離 / 10000)) × 2` に依存する。これは睡眠時そのものの気力消費とは別。

### 3.2 敵の出現解禁距離

[`datas/enemies.json`](../datas/enemies.json) の各敵が `出現距離` を持つ。[`programs/scenes/battle_scene.js`](../programs/scenes/battle_scene.js) は全敵からランダム抽選し、現在距離が必要距離未満なら再抽選する。**距離到達で候補が増える累積方式**であり、それ以前の敵は候補から外れない。同名の別データも別エントリとして抽選対象になる。

| 新たな出現距離 | その地点から追加される敵 |
| ---: | --- |
| 0km | 兎、タヌキ、蛇、牛、鹿、熊 |
| 7.5km | 猛牛 |
| 10km | 森の妖精 |
| 50km | 乳牛、大蛇、大蜘蛛、兎の群れ |
| 55km | 巨大蜘蛛、巨大熊 |
| 75km | 兎の大群、泥蛇、インド人、スパイスソムリエ、ナン職人 |
| 100km | スルメねこ。、ドラゴン |
| 120km | 終焉の龍 |
| 150km | 女の子……？（体力200のデータ） |
| 152.5km | 女の子……？（体力150のデータ） |
| 155km | 女の子……？（体力250のデータ） |

最終的に敵データ25件が候補になる。現行実装は「女の子……？」の撃破時にストーリーへ遷移するため、ストーリーには距離による間接的な到達制約がある。v1.4の汎用トリガー化とは別の現状説明。

### 3.3 距離で変化しない要素

- 戦闘になる基本確率は `battle_rate = 20`（20%）の定数で、距離によって上昇しない。[`programs/global_initializer.js`](../programs/global_initializer.js)、[`programs/scenes/search_scene.js`](../programs/scenes/search_scene.js)
- 通常の探索アイテム抽選は所持道具と食料の探索入手設定で候補を構成し、距離を直接参照しない。敵の追加によってドロップの入手機会は間接的に変わる。[`programs/scenes/get_scene.js`](../programs/scenes/get_scene.js)、[`programs/scenes/win_scene.js`](../programs/scenes/win_scene.js)
- 現行版に背景画像の距離連動や地域データはなく、本書の0／50／100km切替はv1.4で追加予定の機能。

## 4. 残る制作・実装事項

画像9枚の制作・配置、各画像の具体的な表現、共通背景表示処理とアセット読み込み、ストーリー個別背景のオプション対応が必要。距離帯とカテゴリは決定済みのため再検討不要。リフレッシュは従来の表示を維持する。仕様記録はゲームへの実装完了を意味しない。
