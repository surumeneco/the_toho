## 1. 決定したカテゴリ

| カテゴリ | 対象シーン | 距離による切替 |
| --- | --- | --- |
| タイトル | タイトル | なし |
| 拠点昼 | ホーム、制作、持ち物 | なし |
| 拠点夜 | 睡眠 | なし |
| 探索 | 探索、入手、戦闘、勝利、逃走 | **あり。探索カテゴリだけ。** |
| リザルト | ゲームオーバー | なし |
| 履歴 | プレイ履歴、解放ストーリー一覧、実績、図鑑など、v1.4でタイトルから新たに追加する閲覧シーン | なし |
| その他 | ストーリー本文 | なし。個別背景の指定機能を用意し、初期状態では共通背景を使用。 |
| 対象外 | リフレッシュ | 背景画像を設定しない。 |

現行登録は [`programs/main.js`](../programs/main.js) の13シーン。`loading_scene.js` はファイルとして存在するが登録されておらず、画像対象外。新規閲覧シーンは未実装であり、追加時に `scenes` 登録へ `backgroundCategory: 'history'` を指定する。解放ストーリー一覧は「履歴」、そこから再生する本文は「その他」を適用する。

### 背景選択ルール

1. ストーリー本文に個別背景が指定されていれば最優先。初期データには個別指定をせず、`story_default.webp` を使う。
2. 探索5シーンは現在距離（m）以下で最大の開始距離に対応する画像を共有する。
3. 探索以外は距離を参照せずカテゴリ固定背景を使う。最高記録も背景選択には使わない。
4. 探索の50／100km画像が読み込めない場合は0km画像を試し、それも失敗したら従来の背景色に戻す。ストーリー専用画像が失敗した場合は汎用背景を試す。その他の画像も失敗時は従来の背景色に戻す。
5. 画像はUIより背面に描画し、クリック・タッチ判定を妨げない。敵別戦闘背景など、ストーリー以外の個別上書きは行わない。

### 探索の切替距離（確定）

| 現在の到達距離 | 使用する背景 | 開始距離（データ定義値） |
| --- | --- | ---: |
| 0km以上、50km未満 | 探索 0km | `0` m |
| 50km以上、100km未満 | 探索 50km | `50000` m |
| 100km以上 | 探索 100km | `100000` m |

100km以降は上限なし。探索・入手・戦闘・勝利・逃走は同じ距離帯の画像を共有。50kmや100kmにちょうど到達すると新画像になる。敵の出現解禁・気力消費は変更しない。

## 2. 制作・配置する背景画像：計9枚

以下は**コードに設定済みの正確な相対パス**。画像を同じ名前でリポジトリに置けば、ゲーム側のパス変更は不要。

| No. | 背景用途 | 配置先（リポジトリルート相対） |
| ---: | --- | --- |
| 1 | タイトル | `images/backgrounds/title.webp` |
| 2 | 拠点昼（ホーム・制作・持ち物） | `images/backgrounds/base_day.webp` |
| 3 | 拠点夜（睡眠） | `images/backgrounds/base_night.webp` |
| 4 | 探索 0km以上～50km未満 | `images/backgrounds/exploration_000.webp` |
| 5 | 探索 50km以上～100km未満 | `images/backgrounds/exploration_050.webp` |
| 6 | 探索 100km以上 | `images/backgrounds/exploration_100.webp` |
| 7 | リザルト（ゲームオーバー） | `images/backgrounds/result.webp` |
| 8 | 履歴・各種一覧（図鑑・実績等） | `images/backgrounds/history.webp` |
| 9 | その他（ストーリー共通） | `images/backgrounds/story_default.webp` |

- **推奨サイズ：1080×1920px、縦長9:16、全9枚共通。** 現行キャンバスと同寸。異なる比率を渡した場合は歪めず中央基準で拡大・切り抜く（cover表示）。
- **形式は `.webp` で統一。** PNGで制作した場合はWebPへ変換して上記のファイル名で配置するか、コードのパスを変更する。透過は必須ではない。
- 画像にはテキスト・ボタンを描き込まない。描画時に黒35%の半透明オーバーレイを画像の上、UIの下へ重ねて白文字を読みやすくする。
- `images/backgrounds/` は画像をアップロードするための新規ディレクトリ。まだ画像が無い状態でもゲームは起動し、従来の背景色で表示する。**未配置の画像を起動時の `ASSETS` に登録しない。**
- 実装は [`programs/main.js`](../programs/main.js) の `BACKGROUND_FILES` と `install_scene_backgrounds` に集約。GitHub Pagesのサブパス基準URLとバージョン付きURLを使用する。読み込み結果を共有・キャッシュし、シーンの表示内容や操作処理は変更しない。
- 画像9枚を追加・反映する際は、`feature/1.4.0` に正しいパスでアップロードし、そのブランチを配信する環境でページを再読み込みする。`master` 公開版への反映はマージ／リリース後となる。ゲームのバージョン表示は他のv1.4機能が未実装のため現状の `1.3.3` のまま。

### 将来のストーリー個別背景

`register_story_background(storyId, 'images/backgrounds/xxx.webp')` でIDごとの画像パスを登録し、表示中シーンに `storyId` を設定すると個別背景へ切り替わる。あるいは表示中シーンの `storyBackgroundPath` に直接パスを設定できる。未指定・画像読込失敗時は `story_default.webp` を用いる。**現在のストーリーはまだ数値インデックス式のため、IDの紐付けは後続のストーリー改修時に実装する。** 個別背景9枚目以外の素材は今は不要。

## 3. v1.3.3 の距離関連仕様（コード確認）

### 3.1 探索距離と気力

[`programs/scenes/search_scene.js`](../programs/scenes/search_scene.js)：探索1回につき移動距離100m増加。気力消費は更新前の距離 `d`（m）で `5 + floor(d / 10000)`。0～9.9kmで5、10～19.9kmで6、20～29.9kmで7、…と10kmごとに1増加する。9.9kmから10kmへの探索は5消費し、その次から6消費。変化後に気力が負ならゲームオーバー判定。

ホーム・制作・入手・睡眠の警告も `気力 < (5 + floor(距離 / 10000)) × 2` を参照する。睡眠自体の気力消費とは別。

### 3.2 敵の出現解禁距離

[`datas/enemies.json`](../datas/enemies.json) の各敵に `出現距離` があり、[`programs/scenes/battle_scene.js`](../programs/scenes/battle_scene.js) が距離不足の敵を再抽選する。**累積解禁方式**で、それ以前の敵は候補から外れない。同名の別データも別エントリ。

| 新たな出現距離 | その地点から追加される敵 |
| ---: | --- |
| 0km | 兎、タヌキ、蛇、牛、鹿、熊 |
| 7.5km | 猛牛 |
| 10km | 森の妖精 |
| 50km | 乳牛、大蛇、大蜘蛛、兎の群れ |
| 55km | 巨大蜘蛛、巨大熊 |
| 75km | 兎の大群、泥蛇、インド人、スパイスソムリエ、ナン職人 |
| 100km | スルメねこ。、ドラゴン |
| 120km | 終焉の龍 |
| 150km | 女の子……？（体力200） |
| 152.5km | 女の子……？（体力150） |
| 155km | 女の子……？（体力250） |

最終的に敵25件が候補になる。現行ストーリーは「女の子……？」撃破を契機とするため距離による間接制約がある。v1.4汎用トリガー化とは別の現状説明。

### 3.3 距離で変化しない要素

- 戦闘になる基本確率は `battle_rate = 20`（20%）で、距離で増加しない。[`programs/global_initializer.js`](../programs/global_initializer.js)、[`programs/scenes/search_scene.js`](../programs/scenes/search_scene.js)
- 通常の探索アイテム抽選は所持道具と食料の探索入手設定で候補を作成し、距離を直接参照しない。敵の追加によってドロップの入手機会は間接変化する。[`programs/scenes/get_scene.js`](../programs/scenes/get_scene.js)、[`programs/scenes/win_scene.js`](../programs/scenes/win_scene.js)
- 上記は既存v1.3.3の内容。背景の0／50／100km切替は `feature/1.4.0` で新たにコード化した。
