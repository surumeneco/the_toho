既存のシーン登録は [`programs/main.js`](../programs/main.js) にある13シーン。別ファイルの `loading_scene.js` は登録されていないため、現時点のカテゴリ割り当て対象外。新規閲覧シーンの正確な名称・数は実装時に決定する。解放ストーリー一覧は「履歴」に属するが、一覧から開いたストーリー本文の表示には「その他／ストーリー」とそのストーリー専用背景の規則を適用する。

### 背景選択ルール（確定）

1. ストーリーに個別背景があれば最優先する。未指定なら「その他」の固定背景を使用する。ストーリーが発火した距離では背景を変えない。
2. 「探索」の5シーンでは、現在の到達距離以下にある最大の開始距離に対応する背景を選択する。
3. 他のカテゴリは距離を参照せず、カテゴリごとの固定背景を使用する。タイトル・履歴などで最高記録やプレイ中の距離を背景選択に流用しない。
4. カテゴリ背景未設定時や読み込み失敗時は従来の背景色へフォールバックする。探索の開始距離に該当設定がない場合は探索カテゴリのデフォルトを使用する。

具体的な背景アセット、探索背景の切替地点、描画方式は未決定。

## 2. v1.3.3 の距離関連仕様（コード確認）

### 2.1 探索距離と気力

[`programs/scenes/search_scene.js`](../programs/scenes/search_scene.js)：探索が1回進行するごとに移動距離が**100m増加**。気力の消費量は更新前の距離 `d`（m）で `5 + floor(d / 10000)`。つまり、0～9.9kmで5、10～19.9kmで6、20～29.9kmで7、…と**10kmごとに1ずつ増える**。9.9kmから10kmに到達する探索は旧距離で算出するため5消費し、次の探索から6消費する。距離・気力の変化後、気力が負ならゲームオーバー判定に進む。

ホーム・制作・入手・睡眠の気力警告は `気力 < (5 + floor(距離 / 10000)) × 2` を参照する。これは警告表示の閾値であり、睡眠そのものの気力消費（体力欠損に基づく計算）とは別。

### 2.2 敵の出現解禁距離

[`datas/enemies.json`](../datas/enemies.json) の各敵が `出現距離` を持つ。[`programs/scenes/battle_scene.js`](../programs/scenes/battle_scene.js) は全敵からランダム抽選し、現在距離が必要距離未満なら再抽選する。**距離到達で候補が増える累積方式**であり、それ以前の敵は候補から外れない。候補の中に重み設定はなく、同名でも別データなら別エントリとして抽選対象になる。

| 新たな出現距離 | その地点から追加される敵 |
| ---: | --- |
| 0km | 兎、タヌキ、蛇、牛、鹿、熊 |
| 7.5km | 猛牛 |
| 10km | 森の妖精 |
| 50km | 乳牛、大蛇、大蜘蛛、兎の群れ |
| 55km | 巨大蜘蛛、巨大熊 |
| 75km | 兎の大群、泥蛇、インド人、スパイスソムリエ、ナン職人 |
| 100km | スルメねこ。、ドラゴン |
| 120km | 終焉の龍 |
| 150km | 女の子……？（体力200のデータ） |
| 152.5km | 女の子……？（体力150のデータ） |
| 155km | 女の子……？（体力250のデータ） |

最終的に敵データ25件が候補になる。「女の子……？」の3データは同名だが性能・解禁距離の違う別エントリ。`battle_scene.js` ではこの名前の敵を倒した場合にストーリーへ遷移するため、ストーリーにも距離による**間接的な到達制約**がある（ストーリー自体の距離判定ではない）。

### 2.3 距離で変化しない要素

- 戦闘になる基本確率は `battle_rate = 20`（20%）の定数。距離によって上昇しない。[`programs/global_initializer.js`](../programs/global_initializer.js)、[`programs/scenes/search_scene.js`](../programs/scenes/search_scene.js)
- アイテム入手シーンは、所持道具と食料の探索入手設定によって抽選候補を構成する。距離を直接使わない。ただし敵の顔ぶれが増えると討伐ドロップの入手機会は変わる。[`programs/scenes/get_scene.js`](../programs/scenes/get_scene.js)、[`programs/scenes/win_scene.js`](../programs/scenes/win_scene.js)
- 背景画像の距離連動や距離別の地形・地域データは現行版に存在せず、v1.4で新規追加する。

## 3. 次に決めること

「探索」カテゴリだけ、開始距離と背景IDの組を列挙する。候補は既存の敵解禁距離（0、7.5、10、50、55、75、100、120、150、152.5、155km）や10km刻みの気力消費変化を参考にできるが、**ゲーム仕様の変化地点と背景変更地点を一致させる必要はない**。背景を切り替える距離と画像表現が決まるまでは、いずれの候補も背景切替条件として確定しない。
