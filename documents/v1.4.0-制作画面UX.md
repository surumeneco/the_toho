# v1.4.0 制作画面 UX

状態：`feature/1.4.0` に実装済み。実ブラウザでの表示・操作確認は未完了。

## 素材名検索

- 気力表示の下に1行の検索欄を設ける。入力欄の背景は白、右側に「×」クリアボタンを配置する。画面サイズに応じてキャンバスと同じ倍率・位置に追従するHTML入力欄を使用し、日本語入力を扱えるようにする。
- 現在選択している必要道具のレシピだけを対象とし、レシピの `必要素材[][0]` のいずれかに入力文字列が部分一致した場合に表示する。制作物名・道具名は検索対象外。空欄ではすべて表示し、ヒットしない場合は「該当するレシピなし」を表示する。
- 入力時にインクリメンタルに更新する。道具を切り替えても検索語を保持し、その道具内で再検索する。検索語変更・道具変更・制作後の再読み込みでは一覧のスクロール位置を先頭に戻す。
- クリアボタンで入力欄と検索条件を空に戻す。ホームに戻る際は検索語を初期化する。検索欄は制作画面を離れる際にDOMから除去する。
- これまでどおり必要道具の所持状態で選択可能な道具を絞る。検索条件に一致するレシピが0件でも道具切替は可能。制作後に道具の所持状態が変化した場合、道具一覧・検索結果を更新する。

## 性能表示

- 制作物が武器なら、制作物名の下・必要素材見出しの上に `攻撃力：4d3`、`攻撃力：1d10+1d3`、`攻撃力：1d6+1` などを表示する。値は武器の `攻撃力.ダイス` と `攻撃力.固定値` から算出する。
- 制作物が食料なら、同じ位置に `気力回復量：N` を表示する。食料データの `回復量` を1個当たりの値として使用する。
- その他の制作物に性能行は設けない。性能行のあるレシピではウィンドウ高さ、必要素材表示位置、制作ボタンとスクロール範囲を追加の1行に応じて調整する。性能値はレシピJSONに重複保持しない。

## 確認観点

- 素材名の部分一致・不一致・空文字、日本語入力、クリア、道具切替時の条件保持。
- 0件の検索結果、長い一覧のスクロール、フィルタ後の先頭位置、画面上下に隠れた制作ボタンの操作防止。
- 武器の複数ダイス・固定加算、食料の回復量、その他アイテムの表示行数。
- 制作・道具の消費後に現在の条件を再適用すること、戻る操作でHTML入力欄が残らないこと、スマートフォンの入力キーボードと画面サイズ変更。
